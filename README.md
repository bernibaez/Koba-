# KOBA — Kob Cloud ERP 🚀

Sistema ERP Cloud moderno y modular desarrollado por **Kob Cloud** para empresas, supermercados, cadenas comerciales y gestión de inventario, punto de venta (POS), compras, finanzas y reportes.

## 🌟 Características Principales

- **Punto de Venta (POS):** Facturación rápida con soporte de lectores de código de barra, balanzas, atajos de teclado y cierres de caja.
- **Gestión de Inventario & Almacenes:** Control de existencias en tiempo real, alertas de stock mínimo, transferencias entre sucursales y ajustes.
- **Compras & Proveedores:** Órdenes de compra, recepción de mercancía y cuentas por pagar.
- **Finanzas & Caja:** Cierre de turnos (maleta), gastos operativos, arqueo y conciliación.
- **Facturación & Cumplimiento:** Soporte de comprobantes fiscales (NCF) e impresión térmica.
- **Auditoría & Roles:** Control de acceso granular y trazabilidad completa de eventos del sistema.

## 🛠️ Stack Tecnológico

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend / Persistencia:** Supabase (PostgreSQL, Row Level Security, RPCs transaccionales)
- **Reportes:** jsPDF, AutoTable, XLSX, Recharts
